**Inner class Particle (private static):**

```java
private static class Particle {
    float x, y;           // position
    float vx, vy;         // velocity (px/s)
    float size;           // current size in px
    Color color;          // from NoteColorMapper.forPitch()
    long spawnNanos;      // System.nanoTime() at creation
    long lifetimeNanos;   // total lifetime in nanoseconds
    float rotation;       // current rotation in radians
    float rotationSpeed;  // radians per second

    boolean isDead(long nowNanos) {
        return (nowNanos - spawnNanos) >= lifetimeNanos;
    }

    float alpha(long nowNanos) {
        // Linear alpha decay: 1.0 at spawn, 0.0 at death
        long elapsed = nowNanos - spawnNanos;
        return 1.0f - (float) elapsed / lifetimeNanos;
    }
}
```

**updateAndRepaint() (private):**
1. `long now = System.nanoTime();`
2. `particles.removeIf(p -> p.isDead(now));`
3. For each particle: update position `p.x += p.vx * 0.016f; p.y += p.vy * 0.016f;` (16ms step), update rotation `p.rotation += p.rotationSpeed * 0.016f;`
4. `repaint();`

**emit(int note, int velocity) (public):** per D-10, D-11, D-13, D-14

1. Get color: `Color color = NoteColorMapper.forPitch(note);` (D-10)
2. Compute lifetime: `int lifetimeMs = 300 + (velocity * 500 / 127);` (D-13: 300ms at vel=0 → 800ms at vel=127). Convert to nanos: `long lifetimeNanos = lifetimeMs * 1_000_000L;`
3. Compute size: `int size = 1 + (velocity * 7 / 127);` (D-14: 1px at vel=0 → 8px at vel=127)
4. If `particles.size() >= MAX_PARTICLES`, call `mergeOldestParticles()` (D-12)
5. Create new Particle:
   - spawnNanos = System.nanoTime()
   - x, y = center of component (getWidth()/2, getHeight()/2) — actual position set by wiring code. Default to (0,0) with a `setEmitOrigin(float x, float y)` method.
   
   Actually, per Claude's discretion, the emitter origin should be settable. Add field `emitOriginX`, `emitOriginY` (default 0,0) and a setter `setEmitOrigin(float x, float y)`. Particles spawn at emitOrigin with random offset (±10px).

   - Random angle: `random.nextFloat() * 2 * Math.PI` (uniform 0-360 degrees)
   - Random speed: `MIN_SPEED + random.nextFloat() * (MAX_SPEED - MIN_SPEED)` (80-200 px/s)
   - vx = speed * cos(angle), vy = speed * sin(angle)
   - rotation: 0
   - rotationSpeed: `(MIN_ROTATION_SPEED + random.nextFloat() * (MAX_ROTATION_SPEED - MIN_ROTATION_SPEED)) * Math.PI / 180.0`
   - Add to particles list

6. Ensure timer is running: `if (!timer.isRunning()) timer.start();`

**mergeOldestParticles() (private):** per D-12 and Claude's discretion (UI-SPEC merge algorithm)

1. If particles.size() < 2, return (can't merge fewer than 2)
2. Sort by remaining lifetime ascending (oldest = smallest remaining lifetime). Collect 2 oldest.
3. Merged position: (p1.x + p2.x) / 2, (p1.y + p2.y) / 2
4. Merged size: min(p1.size + p2.size, 12.0f)
5. Merged color: color of particle with largest remaining lifetime (most alive)
6. Merged lifetime: average of remaining lifetimes + current elapsed
7. Merged velocity: vector average, preserve magnitude = (|v1| + |v2|) / 2, direction = avg angle
8. Remove the 2 old particles, add the merged particle

**Class signature:** `public class GlitchTransition`

**Static method: applyRgbSplit(BufferedImage source, int redOffsetX, int greenOffsetX, int blueOffsetX, float greenAlpha, float noiseDensity)**

Parameters:
- `redOffsetX`: shift red channel left (negative) or right (positive), in pixels
- `greenOffsetX`: typically 0 (green stays in place)
- `blueOffsetX`: shift blue channel right (positive), in pixels
- `greenAlpha`: alpha multiplier for green channel (0.0-1.0, dips during transition)
- `noiseDensity`: fraction of pixels to randomize (0.0-0.10, adds digital glitch noise)

Algorithm:
1. Get source dimensions: `int w = source.getWidth(); int h = source.getHeight();`
2. Create result: `BufferedImage result = new BufferedImage(w, h, BufferedImage.TYPE_INT_ARGB);`
3. Extract source pixels: `int[] srcPixels = source.getRGB(0, 0, w, h, null, 0, w);`
4. Create `int[] dstPixels = new int[w * h];`
5. For each pixel (y from 0 to h-1, x from 0 to w-1):
   - srcIdx = y * w + x
   - srcPixel = srcPixels[srcIdx]
   - a = (srcPixel >> 24) & 0xFF (preserve alpha)
   - rx = clamp(x + redOffsetX, 0, w-1)
   - gx = clamp(x + greenOffsetX, 0, w-1)
   - bx = clamp(x + blueOffsetX, 0, w-1)
   - r = (srcPixels[y * w + rx] >> 16) & 0xFF
   - g_orig = (srcPixels[y * w + gx] >> 8) & 0xFF
   - g = (int)(g_orig * greenAlpha) (clamped to 0-255)
   - b = srcPixels[y * w + bx] & 0xFF
   - dstPixels[srcIdx] = (a << 24) | (r << 16) | (g << 8) | b
6. Apply noise: for each pixel, if `random.nextFloat() < noiseDensity`, replace the pixel with a random grayscale value while preserving alpha:
   - `int randGray = random.nextInt(256);`
   - `dstPixels[i] = (a << 24) | (randGray << 16) | (randGray << 8) | randGray;`
7. `result.setRGB(0, 0, w, h, dstPixels, 0, w);`
8. Return result

**Private helper: clamp(int val, int min, int max):**
```java
private static int clamp(int val, int min, int max) {
```
