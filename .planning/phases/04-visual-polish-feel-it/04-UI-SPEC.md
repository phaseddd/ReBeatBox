# Phase 04 -- UI Design Contract

> Visual and interaction contract for Phase 4: Visual Polish -- "Feel It."
> Generated by gsd-ui-researcher, verified by gsd-ui-checker.
> **Platform:** Java 17 + Swing (desktop), Radiance 8.5.0 NightShade skin.
> **Adaptation:** This contract uses Java pixel constants, java.awt.Font definitions, and java.awt.Color fields instead of CSS tokens. The "shadcn" and "registry" sections are not applicable to this desktop app.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (custom Swing rendering via `paintComponent` overrides) |
| Skin | Radiance NightShade 8.5.0 (structural styling: corner radii, margins) |
| Component library | Radiance Timeline 8.5.0 (animation), javax.swing (layout/controls) |
| Icon library | Apache Batik 1.19 SVG -> BufferedImage (D-24) |
| Font | SansSerif (UI), Monospaced (note labels) |
| Canvas | java.awt.Graphics2D + ConvolveOp (glow), off-screen BufferedImage (particles) |

Pixel constants used in layout managers and insets. All values are integer pixels (multiples of 4 unless constrained by existing layout).

| Token | Value | Usage |

| sm | 6px | FlowLayout hgap (ControlBar), inline element spacing |
| md | 8px | GridLayout gaps (DrumPadGrid 4x4), border thickness |

**Source:** Pre-populated from existing codebase patterns (ControlBar FlowLayout(LEFT, 6, 4), DrumPadGrid GridLayout(4, 4, 8, 8), struts of 10px/4px, EmptyBorder(0, 12, 0, 12)). No changes required for Phase 4 -- these are the existing spacing constants that new components must match.

## Typography

Java Font definitions. Radiance NightShade sets the base UI font; these tokens override for specific roles.

| Role | Family | Style | Size (pt) | Line Height | Usage |
|------|--------|-------|-----------|-------------|-------|
| Body | SansSerif | PLAIN | 12 | default (1.2) | Labels: BPM, Volume, Time, PadButton text |
| Label | SansSerif | PLAIN | 10 | default (1.2) | PadButton compact labels, small annotations |
| Heading | SansSerif | BOLD | 18 | default (1.2) | PlaceholderPanel title, section headers |
| Mono | Monospaced | PLAIN | 9 | default (1.0) | KeyboardHintPanel note labels (C4, D4, etc.) |

**Strict rules:**
- Exactly 2 font families: **SansSerif** (all UI text) and **Monospaced** (pitch/scientific labels only).
- Exactly 2 font weights: **PLAIN** (Style=0) and **BOLD** (Style=1). No ITALIC anywhere.
- Line height is inherited from Java's default FontMetrics. No custom leading manipulation.
- Font sizes must come from the set {9, 10, 12, 18} only. No ad-hoc sizes.
- KeyboardHintPanel key labels (Q, W, E...) use the Label token (SansSerif PLAIN 10pt). The existing 11pt KEY_LABEL_FONT is deprecated and must be replaced.

**Source:** Body and Label from existing PadButton.setFont(SansSerif, PLAIN, 10) and ControlBar labels. Heading from PlaceholderPanel (SansSerif, BOLD, 18). Mono from KeyboardHintPanel NOTE_LABEL_FONT (Monospaced, PLAIN, 9). Font size restriction added as Claude's discretion to enforce consistency.

## Color

Semantic Color contract via ThemeManager (D-01). No component may use `new Color(0x...)` -- all colors are referenced from ThemeManager constants. Radiance NightShade provides structural styling only (D-04).

### Palette Hierarchy (60/30/10)

| Role | Token | Hex | RGB | Usage |
|------|-------|-----|-----|-------|
| Dominant (60%) | BG_ROOT | #0A0A14 | (10, 10, 20) | PianoRollPanel canvas, GlassPane base, deepest backgrounds |
| Secondary (30%) | BG_SURFACE | #12122A | (18, 18, 42) | SidebarPanel, KeyboardHintPanel, panel backgrounds |
| Secondary (30%) | BG_ELEVATED | #1A1A3E | (26, 26, 62) | Button default fills (PadButton, ControlBar), slider tracks |
| Accent (10%) | *(rainbow)* | *(hue-zoned)* | HSB(sat=0.85, bri=0.95) | Button borders on hover/press, pressed fills, glow, particles |

**Source:** D-03 (three-tier backgrounds). The 60% BG_ROOT and 30% BG_SURFACE+ELEVATED directly implement the color theory split. The 10% accent is the rainbow neon palette (D-02).

### Semantic Hues (D-02)

Each UI region gets a distinct hue zone from the rainbow. Saturation and brightness are constant across all zones at 0.85 and 0.95 respectively.

| Region | Hue Constant | Hue Value | Color (approx) | Example |
|--------|-------------|-----------|----------------|---------|
| Transport controls | HUE_TRANSPORT | 0.55 | Cyan-Blue #00E5FF | Play/Pause/Stop/Restart button borders |
| Drum pads | HUE_DRUM_PADS | 0.80 | Purple-Magenta #E040FB | PadButton hover/pressed borders |
| Sidebar | HUE_SIDEBAR | 0.65 | Blue-Purple #7B68EE | SidebarPanel toggle, border accents |
| Keyboard | HUE_KEYBOARD | 0.50 | Cyan #00E5FF | Pressed key border and label |
| File open | HUE_TRANSPORT | 0.55 | Cyan-Blue #00E5FF | Open button border (shares transport zone) |

All neon accent colors are generated via `ThemeManager.accentForHue(float hue)` which wraps `Color.getHSBColor(hue, 0.85f, 0.95f)`.

### Semantic Text Colors

| Token | Hex | Usage |
|-------|-----|-------|
| TEXT_PRIMARY | #E0E0E0 | All body labels: BPM, Volume, Time, PadButton default text |
| TEXT_SECONDARY | #808080 | Diminished text: KeyboardHintPanel idle key labels, placeholder hints |
| TEXT_ACCENT | #00E5FF | Pressed state labels: PadButton pressed text, KeyboardHintPanel pressed key label |

### Semantic Border Colors

| Token | Hex | Usage |
|-------|-----|-------|
| BORDER_IDLE | #2A3A5E | Default component border (all buttons, panels) |
| BORDER_HOVER | *(accentForHue)* | Button borders on mouse hover -- hue from component's region |
| BORDER_PRESS | *(accentForHue)* | Button borders on mouse press -- same hue as hover, brighter |

### Accent Reserved For (exhaustive list)

The 10% neon accent is reserved exclusively for these elements. No other elements may use accent colors.

1. Button borders on hover state (D-05)
2. Button borders on press state (D-05)
3. PadButton pressed fill (#003344, a dark cyan derived for contrast)
4. KeyboardHintPanel pressed key border + label (D-30, D-31)

### Destructive Color

| Token | Hex | Usage |
|-------|-----|-------|
| DESTRUCTIVE | #FF4444 | PadButton context menu "Reset Pads" item foreground ONLY |

No other destructive actions exist in Phase 4. If future phases add delete/remove actions, they use this same token.

### KeyboardHintPanel State Colors (D-30, D-31)

| State | Key Type | Fill | Border | Label Text |
|-------|----------|------|--------|------------|
| Idle | White key | #2A2A2A | #3A3A3A | #808080 (TEXT_SECONDARY) |
| Idle | Black key | #1A1A1A | #2A2A2A | #606060 |
| Pressed | Any key | *(unchanged idle fill)* | #00E5FF (accent) | #00E5FF (TEXT_ACCENT) |

Switch is instant (no animation) per D-31. This is performance-critical for live playing.

### Velocity -> Alpha Mapping (D-27, D-28, D-29)

Applied in PianoRollPanel.drawSingleNote(). Alpha is derived linearly from MIDI velocity (0-127).

| Location | Velocity 0 Alpha | Velocity 127 Alpha | Mapping |
|----------|-----------------|--------------------|---------|
| Above trigger line | 0.30 | 1.00 | alpha = 0.30 + (vel/127) * 0.70 |
| Below trigger line | 0.15 | 0.40 | alpha = 0.15 + (vel/127) * 0.25 |

Preserves the above/below brightness distinction from Phase 2 D-06 while making velocity visually meaningful.

## Animation Contract

Phase 4 introduces three animation systems. Each has a specific contract for timing, easing, and visual parameters.

### Button Hover/Press Animation (UI-03, D-05, D-06, D-07)

Driven by Radiance ephemeral Timeline. Applied uniformly to ALL interactive buttons.

| Event | Property | From | To | Duration | Easing |
|-------|----------|------|----|----------|--------|
| Mouse enter | borderColor | BORDER_IDLE (#2A3A5E) | accentForHue(regionHue) | 200ms | SplineEase(0.4, 0.0, 0.2, 1.0) |
| Mouse exit | borderColor | accentForHue(regionHue) | BORDER_IDLE (#2A3A5E) | 250ms | SplineEase(0.4, 0.0, 0.2, 1.0) |
| Mouse press | scale | 1.00x | 0.95x | 75ms (attack) | Linear or fast ease-in |
| Mouse release | scale | 0.95x | 1.00x | 150ms (release) | SplineEase(0.4, 0.0, 0.2, 1.0) |

**Affected components (exhaustive list per D-06):**
1. ControlBar transport buttons: Play, Pause, Stop, Restart (4)
2. ControlBar file open button (1)
3. PadButton grid: all 16 pads
4. SidebarPanel toggle button (1)

**Total: 22 buttons** with uniform animation behavior.

**Non-animated exception:** KeyboardHintPanel key highlights use instant color switch (D-31). No Timeline animation on keyboard keys -- latency-sensitive for live playing.

### Particle System (GLITCH-01, D-08 through D-15)

| Parameter | Value | Source |
|-----------|-------|--------|
| Max particles | 200 | D-12 |
| Shape | Squares/rectangles, random rotation, glow border | D-08 |
| Size range | 1px (vel=0) to 8px (vel=127), linear | D-14 |
| Lifetime range | 300ms (vel=0) to 800ms (vel=127), linear | D-13 |
| Color | NoteColorMapper.forPitch(noteNumber) | D-10 |
| Render target | JFrame GlassPane (transparent to mouse events) | D-09 |
| Animation timer | javax.swing.Timer(16ms), independent from PianoRollPanel | D-15 |
| Trigger source | NoteEventBus (sequencer) + LiveNoteEventListener (live) | D-11 |
| Overflow behavior | Merge oldest 2-3 particles into one larger particle | D-12 |

**Particle motion trajectory (Claude's discretion):**
- Initial direction: random angle 0-360 degrees, uniform distribution
- Initial speed: 80-200 px/s, random uniform distribution
- Alpha decay: linear from 1.0 at spawn to 0.0 at death (synchronized with lifetime)
- No gravity, no acceleration, no physics -- constant velocity linear trajectory
- Rotation: constant angular velocity 90-360 degrees/s, random per particle

**Merge algorithm (Claude's discretion):**
- Select oldest 2 particles (by remaining lifetime, ascending)
- Merged position: arithmetic mean of selected particle positions
- Merged size: sum of selected particle sizes, capped at 12px
- Merged color: color of the particle with the largest remaining lifetime
- Merged lifetime: average of selected particle remaining lifetimes
- Merged velocity: vector average of selected particle velocities, magnitude preserved

### Glitch Transition (GLITCH-02, D-16 through D-19)

| Parameter | Sidebar Toggle | File Load | Source |
|-----------|---------------|-----------|--------|
| Duration | 150ms | 300ms | D-18 |
| Effect | RGB channel separation + noise | RGB channel separation + noise | D-17 |
| Method | Component snapshot, Timeline-driven offsets | Component snapshot, Timeline-driven offsets | D-19 |
| Red channel | Shift left, max offset 15px | Shift left, max offset 25px | Claude's discretion |
| Blue channel | Shift right, max offset 15px | Shift right, max offset 25px | Claude's discretion |
| Green channel | No horizontal shift, alpha dips to 0.85 at peak | No horizontal shift, alpha dips to 0.85 at peak | Claude's discretion |
| Noise overlay | 5% pixel randomization at transition peak | 8% pixel randomization at transition peak | Claude's discretion |
| Offset curve | Bell curve (peak at timelinePosition=0.5, 0 at start/end) | Bell curve (peak at timelinePosition=0.5, 0 at start/end) | Claude's discretion |

**Transition lifecycle:**
1. Capture BufferedImage snapshot of target component at transition start
2. Apply RGB split to snapshot with Timeline-interpolated offsets
3. Paint glitched snapshot over component during transition
4. At Timeline.DONE, reveal the actual updated component state
5. Dispose snapshot BufferedImage

| 12 | drum-mode | 24x24 | Mode indicator (if implemented) |
| 13-20 | *(reserved)* | -- | Phase 5 content panel, demo browser, recent files |

### Icon Design Guidelines (Claude's discretion)

- **Stroke weight:** 2px, sharp corners (stroke-linejoin: miter)
- **Fill:** None (outline style) for transport/mode icons; 30% alpha neon fill for app-icon
- **Glow treatment:** SVG filter `feGaussianBlur stdDeviation="1.5"` + `feMerge` on a duplicate path with reduced opacity
- **Aspect ratio:** All icons square viewBox (e.g., "0 0 24 24" for 24px icons, scaled to render size)
- **Color:** Icons render in TEXT_PRIMARY (#E0E0E0) by default. The SVG should NOT hardcode fill colors -- use `fill="currentColor"` so ThemeManager can tint them.
- **Cyber aesthetic:** Angular shapes, diagonal cuts, hexagonal or diamond play symbol, not rounded/circular. Digital/grid motifs.

### Loading Contract

- Loaded at startup via SvgIconLoader (Batik ImageTranscoder)
- Cached as `Map<String, Map<Integer, BufferedImage>>` keyed by icon name then size
- Pre-render at the fixed sizes listed above (no runtime resizing needed)
- Icons stored in `src/main/resources/icons/` as `.svg` files
- Batik modules required: batik-transcoder, batik-awt-util, batik-bridge, batik-dom, batik-ext, batik-gvt, batik-svg-dom, batik-util, batik-xml, batik-parser, batik-css. Exclude batik-anim, batik-script, batik-svggen.
