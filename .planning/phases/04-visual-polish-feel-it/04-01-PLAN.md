```java
/**
 * Maps MIDI velocity (0-127) to alpha for note bar rendering.
 * Preserves the above/below trigger line brightness distinction from Phase 2 D-06.
 *
 * @param velocity     MIDI velocity 0-127
 * @param aboveTrigger true if note is above the trigger line (future/current notes)
 * @return alpha value: 0.30-1.00 (above) or 0.15-0.40 (below)
 */
public static float velocityToAlpha(int velocity, boolean aboveTrigger) {
    float v = velocity / 127.0f;
    if (aboveTrigger) {
        return 0.30f + v * 0.70f;  // 0.30 at vel=0, 1.00 at vel=127
    } else {
        return 0.15f + v * 0.25f;  // 0.15 at vel=0, 0.40 at vel=127
    }
}
```

**Inner class BufferedImageTranscoder (package-private):**
```java
static class BufferedImageTranscoder extends ImageTranscoder {
    private BufferedImage img;

    @Override
    public BufferedImage createImage(int w, int h) {
        return new BufferedImage(w, h, BufferedImage.TYPE_INT_ARGB);
    }

    @Override
    public void writeImage(BufferedImage img, TranscoderOutput output) {
        this.img = img;
    }

    public BufferedImage getBufferedImage() { return img; }
}
```

**Cache field:**
```java
private static final Map<String, Map<Integer, BufferedImage>> cache = new HashMap<>();
```

**loadSvg(String name, int width, int height):**
1. Check cache: `cache.getOrDefault(name, Collections.emptyMap()).get(width)` — if non-null, return it
2. Build resource path: `"/icons/" + name + ".svg"`
3. Get InputStream: `SvgIconLoader.class.getResourceAsStream(iconPath)`
4. If stream is null, throw `IllegalArgumentException("SVG icon not found: " + iconPath)`
5. Create `BufferedImageTranscoder`, set TranscodingHints:
   - `KEY_WIDTH` → (float) width
   - `KEY_HEIGHT` → (float) height
   - `KEY_XML_PARSER_VALIDATING` → Boolean.FALSE
   - `KEY_DOM_IMPLEMENTATION` → `SVGDOMImplementation.getDOMImplementation()`
   - `KEY_DOCUMENT_ELEMENT_NAMESPACE_URI` → `SVGConstants.SVG_NAMESPACE_URI`
   - `KEY_DOCUMENT_ELEMENT` → "svg"
6. Call `transcoder.transcode(new TranscoderInput(svgStream), null)`
7. `BufferedImage result = transcoder.getBufferedImage()`
8. Cache: `cache.computeIfAbsent(name, k -> new HashMap<>()).put(width, result)`
9. Return result

**preload() method:** Pre-loads all 14 icons at their fixed sizes. Returns void. Errors logged to System.err, not thrown.
