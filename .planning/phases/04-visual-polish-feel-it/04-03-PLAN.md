### Change 2: Add velocityToAlpha() method

Insert this static method after the existing `drawGlowingBar()` method (after line 452, before `buildGaussianKernel()`):

```java
/**
 * Maps MIDI velocity (0-127) to an alpha value for note bar opacity.
 * Per D-27, D-28, D-29. Preserves the above/below trigger line brightness
 * distinction from Phase 2 D-06.
 *
 * <p>Above trigger line: alpha 0.30 (vel=0) -> 1.00 (vel=127)
 * <p>Below trigger line: alpha 0.15 (vel=0) -> 0.40 (vel=127)
 *
 * @param velocity     MIDI velocity 0-127
 * @param aboveTrigger true if the note bar is above the trigger line
 * @return alpha value for compositing this note bar
 */
private static float velocityToAlpha(int velocity, boolean aboveTrigger) {
    float v = velocity / 127.0f;
    if (aboveTrigger) {
        return 0.30f + v * 0.70f;
    } else {
        return 0.15f + v * 0.25f;
    }
}
```

NOTE: This method is `private static` in PianoRollPanel — it does NOT import from ThemeManager because both Plan 04-01 and Plan 04-03 are Wave 1 (parallel). Plan 04-04 will optionally deduplicate this with ThemeManager.velocityToAlpha().
